# 例行任务（Routines）

| 例行任务 | 时间 | 执行方式 |
|---|---|---|
| 每日简报（调度动态、待决策事项） | 每天 08:00 | CEO 汇总共享上下文生成 |

## 开启方式

例行任务默认关闭，推荐直接用 WorkBuddy 内置自动化能力（对应注册表 `automation` 条目），或用系统定时工具（cron / Windows 任务计划）触发：

```bash
node src/index.js briefing
```

## 说明

- 简报内容来自共享上下文：每次 `dispatch` 的分派记录会自动汇总进简报。
- 待定制开发的任务会在简报「待决策」一节单独标出，提醒老板拍板。
