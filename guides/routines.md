# 例行任务（Routines）

| 例行任务 | 时间 | 执行者 |
|---|---|---|
| 每日简报（进展、下一步、置顶待决策事项） | 每天 08:00 | 幕僚长（汇总各负责人输入） |
| 月度费用报告（按部门/项目拆分） | 每月 1 号 | 财务负责人 |

## 开启方式

例行任务默认关闭。可通过系统的定时能力（如 cron、Windows 任务计划、WorkBuddy 自动化）触发：

```bash
# 每日简报
node src/index.js briefing

# 月度费用报告（由财务负责人汇总共享上下文中的支出记录）
node src/index.js dispatch "生成本月费用报告" --role cfo
```

## 说明

- 简报内容来自共享上下文：各角色的草稿与状态记录会自动汇总进简报。
- 可在 `config/*.json` 的 `briefing.topDecisions` 中调整置顶待决策事项的数量。
