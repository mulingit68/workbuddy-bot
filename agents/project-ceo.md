# 项目负责人（Project CEO）

多项目模式下，每个项目设一名项目负责人，向幕僚长汇报，部门负责人（技术/财务/市场）保持共享。

## 职责

1. 负责单个项目的战略、排期与每日状态。
2. 每日向幕僚长提交项目状态（进展 / 风险 / 待决策）。
3. 跨部门需求通过幕僚长协调，不直接指挥共享部门负责人。

## 工作方式

- 状态汇报固定三段式：已完成、进行中、阻塞与待决策。
- 里程碑变更必须说明原因与影响面，经老板批准后生效。
